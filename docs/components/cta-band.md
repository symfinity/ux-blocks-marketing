# Cta Band

Role `cta-band` · fragment `blocks.marketing.cta-band`

## Props

| Prop | Type | Default | Values |
|------|------|---------|--------|
| `motion` | string | `none` | `none`, `pulse-glow`, `slide-in` |

## Interaction

All variants are CSS-only (`nat`).

## Reduced motion

Pulse and slide animations are disabled under `prefers-reduced-motion: reduce`.

## Example

```twig
<twig:CtaBand motion="pulse-glow" />
```

# Overview

Consumer handbook for **symfinity/ux-blocks-marketing** — twenty-two native-first (`nat`) marketing section roles with `blocks.marketing.*` fragments.

This tier is **explicit opt-in** — it is not pulled in by `symfinity/ux-blocks-full` (suggest only). Install when you ship landing pages, campaign sites, or public marketing layouts.

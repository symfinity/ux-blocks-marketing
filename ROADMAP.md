## Details

### 0.1.x - Initial marketing catalog

Basic marketing components

### 0.2.x — Section variants and layouts

Additional layout variants, alternative hero compositions, extended pricing layouts, expanded testimonial layouts, richer bento arrangements, configurable spacing presets, responsive section composition

### 0.3.x — Conversion components

Waitlist sections, contact sections, lead capture layouts, feature comparison variants, roadmap sections, FAQ improvements, announcement banners, trust indicators

### 0.4.x — Content and storytelling

Timeline sections, case studies, customer stories, metrics showcases, company overview sections, mission and values layouts, editorial content patterns

### 0.5.x — Responsive refinement

Container adaptations, improved mobile compositions, adaptive grid behavior, better image handling, responsive typography presets, layout consistency improvements

### 0.6.x — Accessibility and localization

Accessibility review, keyboard navigation improvements, landmark optimization, localization support, RTL validation, semantic markup refinements

### 0.7.x — Theme integration

Deeper UI Kernel integration, additional design token hooks, variant customization, theme-aware defaults, color role alignment, typography integration

### 0.8.x — Production polish

Performance improvements, CSS optimization, reduced bundle size, documentation expansion, additional examples, showcase layouts, migration guidance

### 0.9.x — Stabilization

API cleanup, deprecation review, component contract freeze, documentation completion, testing expansion, final consistency pass

### 1.0.x — Stable API

Semver-stable component contracts, stable fragment registry, long-term compatibility guarantees, complete handbook
